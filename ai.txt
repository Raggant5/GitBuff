In this project, we used ai to 1. Write Tests and create Test Coverage for our code 2. Ask it questions  to help us to deeper understand Clean Architecture concepts, SOLID Principles and Design Patterns in order to apply them to our code (eg. we would ask it a conceptual question such as, "should a presenter call a controller", and then based on it's answer we would structure and write the code ourselves), and 3. We used it to ask us questions about Clean Architecture, etc to help us prepare for the presentation. We did not use AI to write or generate any code for us, other than the tests, as mentioned before.
